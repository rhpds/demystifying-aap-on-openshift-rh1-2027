== Troubleshooting

=== Step 1: Run the Break Scenario job

Log into AAP using the *AAP - Scenario 4 (ALIA)* tab. Navigate to *Automation Execution → Templates* and launch the *Break Scenario* job template.

The job template you just ran is configuring the Lightspeed chat bot, it takes a few minutes to deploy. You can watch the `lightspeed-operator-manager` pod logs to see when it is ready.

Please wait for it to complete before proceeding.

=== Step 2: Confirm the ALIA icon is present and attempt to chat with it

Log into AAP. Confirm the ALIA chat icon is visible in the interface — click on it and attempt to send a message. Note that the assistant does not respond.

image::chat_icon.png[The ALIA chat icon in the AAP Gateway UI, width=317, align="left", link=self, window=_blank]

image::alia_chat_ui.png[ALIA chat panel open with no response, align="left", link=self, window=_blank]

=== Step 3: Inspect Lightspeed pod logs

Open the *OpenShift Console* and navigate to *Workloads → Pods*. Filter by your namespace.

Identify the `lightspeed-api` and `chatbot` pods and review their *Logs* tabs for connection errors related to the LLM backend.

Note: If you do not see `lightspeed-api` or `lightspeed-chatbot` pods, please verify that the `lightspeed-operator-manager` pod has finished deployment

=== Step 4: Identify the misconfiguration

Compare what the pods are trying to connect to against the correct ALIA configuration values above. The issue will be visible in the pod logs or in the Lightspeed configuration secret.

Navigate to *Workloads → Secrets* in the OpenShift Console to inspect the chatbot configuration secret.

=== Step 5: Fix the issue

Once you have identified the misconfiguration, apply the fix through the OpenShift Console.

Refer to the solution page if needed: xref:module-05-alia-lightspeed-solution.adoc[Solution: ALIA Lightspeed issues]

=== Step 6: Verify

After applying the fix and allowing the Lightspeed pods to reconcile, log back into AAP, click the ALIA chat icon, and confirm the assistant is now responding to messages.

== Hint

The ALIA service requires a valid connection to a Large Language Model. Review the logs for the Lightspeed API and chatbot pods; the error will indicate what model or endpoint is being used and why it is failing. Compare this against the correct configuration values shown above.
